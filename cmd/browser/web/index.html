    Connection troubleshooting

    Use a recent Chrome or Edge on localhost. Start the Go endpoint with -origin http://localhost:8443. Allow loopback UDP on port 4433.

    If connection setup fails, check endpoint logs, certificate expiration, and the pin. Pinned development certificates must use ECDSA P-256 and be valid for at most 14 days. Use go run ./cmd/certgen to create the supported seven-day certificate. Restart both servers after changing certificates.

    A datagram timeout can mean packet loss; it is not proof that WebTransport is unsupported. No WebSocket or HTTP fallback is used.
